# 💳 Credit Card Financial Analysis | Power BI

A Power BI project focused on analyzing credit card transactions, customer behavior, credit utilization, and financial risk using **DAX**.

### 📊 Key Analysis
- Running totals and 4-week moving averages
- Month-over-month (MoM) and week-over-week (WoW) transaction growth
- Customer acquisition cost (CAC) ratio
- Credit utilization and interest-to-revolving-balance ratio
- Top 5 clients by transaction amount
- Customer churn indicator and delinquency rate
- Credit risk scoring and high-risk client identification
- Income vs. credit limit correlation
- Customer satisfaction by card category
- Personal loan approval vs. credit limit analysis

### 🛠️ Tools Used
- Power BI
- DAX
- Data Modeling & Visualization

### 🎯 Objective
To analyze financial performance and customer behavior, identify potential credit risks, and generate insights that support better banking decisions.
